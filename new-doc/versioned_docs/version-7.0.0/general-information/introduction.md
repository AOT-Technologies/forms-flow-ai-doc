# Introduction

**formsflow.ai** is an open source platform that lets organizations build and deploy business applications without writing code. By combining a dynamic form builder, an identity framework, and a workflow engine, it streamlines processes from data entry through approval, reducing manual effort and ensuring consistency.

## Key Components and Benefits

1. **Dynamic Form Builder**  
   A drag and drop interface lets designers create web forms visually. You simply place fields for text, dates, attachments, and more onto the canvas. This eliminates hand coding of HTML and JavaScript, saving development time and lowering the barrier to entry for non technical users.

2. **Identity and Access Management**  
   *formsflow.ai* uses Keycloak for user authentication and role based permissions. Administrators can create and assign assign roles to users and thus set access levels for each workflow step. This ensures sensitive data remains protected and that each user sees only the tasks relevant to their role.

3. **Low Code Workflow Engine**  
   The workflow engine connects form submissions to automated business processes. Designers define tasks, decision points, and notifications through a visual process modeler. When a user submits a form, the engine routes tasks to the right team members, enforces business rules, and logs each step for auditability.

4. **Deployment Flexibility**  
   You can host *formsflow.ai* on public clouds like AWS or Azure or run it on your own servers. This flexibility lets organizations comply with data residency requirements and scale resources as needed.

## Why formsflow.ai Matters

- **Faster Time to Market**  
  Eliminating manual coding accelerates development cycles. Business teams can prototype and iterate on forms and workflows without waiting for IT resources.

- **Improved Accuracy and Compliance**  
  Standardized forms and automated routing reduce errors and ensure that each submission follows defined approval paths. Detailed audit logs make it easier to demonstrate compliance with regulations.

- **Cost Efficiency**  
  As an open source solution, *formsflow.ai* removes licensing fees. Organizations pay only for hosting, support, and any custom integrations they require.

- **User Empowerment**  
  Citizen developers and business analysts gain the tools to build applications aligned with their domain expertise. This shifts routine tasks away from overburdened development teams.
