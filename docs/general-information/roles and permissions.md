# Roles & Permissions

---

### Create New Roles

1. On the **Roles** page (**Manage > Roles**), you can create or edit roles within formsflow.ai.

   ![Image](/img/7.0.0/Screenshot-2024-12-10-153757.png)

2. To create a new role, click **Create New Role** in the top right corner. In the popup, add the role name, description, and toggle features/permissions for the role.

   ![Image](/img/7.0.0/Screenshot-2024-12-10-154222.png)

3. Click **Create** at the bottom of the popup when satisfied with the selected permissions.

4. Edit permissions by clicking the edit button beside each role in the **Actions** column.

### Assign Roles to Users

1. Assign roles to users on the **Users** page (**Manage > Users**).

   ![Image](/img/7.0.0/Screenshot-2024-12-10-154719.png)

2. Find the user in the table, click **Add Role**, select the roles to assign in the popup, and click **Done**.

   ![Image](/img/7.0.0/Screenshot-2024-12-10-154903.png)

   **Note**: _To remove a role, click the "x" button next to the role. The role will be removed immediately._
