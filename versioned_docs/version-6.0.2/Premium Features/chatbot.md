# Flow-E: The AI-Assisted Form Creation

---

formsflow.ai incorporates AI chat assist support for form creation, enabling users to interact with a GPT-powered AI chatbot. This chatbot understands user queries, prompts, and instructions related to form design, generating forms based on the provided input.

### Steps

1. Log in as a designer and click on **Create Form**.

   ![Image](/img/chatbot/chat_step1.png)

2. Click the **Flow-E** button located at the bottom right.

   ![Image](/img/chatbot/chat_step2.png)

3. Click the **Generate Form Design** button to access the form design prompt.

   ![Image](/img/chatbot/chat_step3.png)

4. Provide the specific requirements to create a form.

   ![Image](/img/chatbot/chat_step4.png)

   ![Image](/img/chatbot/chat_step5.png)

5. Preview the generated form.

   ![Image](/img/chatbot/chat_step6.png)

   ![Image](/img/chatbot/chat_step7.png)

6. Apply the changes or modify the prompt by selecting the appropriate option.
