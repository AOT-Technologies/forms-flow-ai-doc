# Introduction

**formsflow.ai** is an open source platform that lets organizations build and deploy business applications without writing code. By combining a dynamic form builder, an identity framework, and a workflow engine, it streamlines processes from data entry through approval, reducing manual effort and ensuring consistency.

## Key Components

1. **Dynamic Form Builder**  
   A drag and drop interface lets designers create web forms visually. You place fields for text, dates, attachments, and more onto the canvas. This removes the need to hand code HTML and JavaScript, saving development time and lowering the barrier for non technical users.

2. **Identity and Access Management**  
   *formsflow.ai* uses Keycloak for user authentication and role based permissions. Administrators create roles, assign them to users, and set access levels for each workflow step. This keeps sensitive data protected and ensures each user sees only the tasks relevant to their role.

3. **Low Code Workflow Engine**  
   The workflow engine connects form submissions to automated business processes. Designers define tasks, decision points, and notifications through a visual process modeler. When a user submits a form, the engine routes tasks to the right team members, enforces business rules, and logs each step for auditability.

4. **Reporting and Analytics**  
   The analytical engine lets you build custom dashboards that display the data most relevant to your organization. Track submission metrics and gain actionable insights from form responses.

5. **Deployment Flexibility**  
   Deploy formsflow.ai on public clouds such as AWS or Azure, on your own servers, or via our custom hosting packages for compute, storage and data management. This flexibility lets organizations comply with data residency requirements and scale resources as needed.

## Features and Benefits

1. **Centralized Submission Portal**  
   Users access all forms in one place, reducing confusion and streamlining the experience.

2. **Unified Request Dashboard**  
   Service teams see every open request in a single view. They can filter, sort, and assign tasks to the right people, improving response time.

3. **Predefined Workflows**  
   Administrators set the steps each request must follow. This enforces business rules and maintains compliance at every stage.

4. **Real Time Tracking and Notifications**  
   Users receive status updates as their requests move through the workflow. Stakeholders can monitor progress and act when needed, cutting down delays.

5. **Built-in Reporting**  
   The platform gathers data on request volume, processing time, and bottlenecks. Teams use these insights to refine processes and meet service targets.

## Why formsflow.ai Matters

- **Faster Time to Market**  
  Removing manual coding accelerates development cycles. Business teams can prototype and iterate on forms and workflows without waiting for IT resources.

- **Improved Accuracy and Compliance**  
  Standardized forms and automated routing reduce errors and ensure that each submission follows defined approval paths. Detailed audit logs make it easy to demonstrate compliance with regulations.

- **Cost Efficiency**  
  As an open source solution, *formsflow.ai* has no licensing fees. Organizations pay only for hosting, support, and any custom integrations they require.

- **User Empowerment**  
  Citizen developers and business analysts gain tools aligned with their domain expertise. This shifts routine tasks away from overburdened development teams.
