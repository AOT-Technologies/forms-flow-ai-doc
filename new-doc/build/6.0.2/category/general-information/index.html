📄️ Introduction

formsflow.ai is a completely free, open source low code platform designed to help make the process of bringing an application to life easy!

📄️ About the project

AOT Technologies started the formsflow.ai project to give end users the ability to fill in a form to be processed. The software can also report on form metrics and data.
