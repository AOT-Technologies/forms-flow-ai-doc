# Flow: Task Filters

---

In `Review > Tasks`, you can easily create and choose filters to organize tasks based on specific criteria. Simply select **Create New Filter** to access a screen where you can configure filters according to your preferences, offering various options for customization.

Please refer [here](https://aot-technologies.github.io/forms-flow-ai-doc/bpm_abstraction.html) for the relevant guidelines.
