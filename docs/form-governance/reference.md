# Form governance: reference

This page lists every form governance action in formsflow.ai 8.4, the permission each one needs, and where to find it.

## Availability

- **Editions:** Go, Professional, Enterprise
- **Deployment:** SaaS and self-hosted

## Actions and permissions

Permissions are named as they appear on the role editor in **Manage › Roles**. A user can do an action if any of their roles grants the permission.

| What you want to do | Permission needed | Where to find it | Available through |
| --- | --- | --- | --- |
| View the governed content library | Manage › Governed content | Manage › Content | formsflow.ai web app, REST API |
| Turn governed content on or off | Manage › Organization (Billing), Manage › Governed content | Manage › Organization › Governed Content | formsflow.ai web app |
| Create a governed content block | Manage › Governed content | Manage › Content › Create new block | formsflow.ai web app, REST API |
| Edit a block's wording | Manage › Governed content | Manage › Content › Edit | formsflow.ai web app, REST API |
| Retire a block | Manage › Governed content | Manage › Content › Edit ▾ › Retire; or Manage › Content › Edit › Retire block | formsflow.ai web app, REST API |
| View a retired block | Manage › Governed content | Manage › Content › View | formsflow.ai web app, REST API |
| Get required content on a new form | Design › Manage forms & flows you create and that are shared with you | Build › Forms › Create New Form › Create a form or flow from scratch using Form Builder › Builder | formsflow.ai web app |
| Move a governed block on a form | Design › Manage forms & flows you create and that are shared with you | Build › Forms › &lt;form&gt; › Form › Builder | formsflow.ai web app |
| Add or remove optional content on a form | Design › Manage forms & flows you create and that are shared with you | Build › Forms › &lt;form&gt; › Form › Content | formsflow.ai web app |
| Remove retired content from a form when it's saved | Design › Manage forms & flows you create and that are shared with you | Build › Forms › &lt;form&gt; › Save | formsflow.ai web app, REST API |
| Add missing required content before publishing | Design › Manage forms & flows you create and that are shared with you | Build › Forms › &lt;form&gt; (alert in the header) | formsflow.ai web app |
| See which governed content a form carries | Design › View forms & flows \| Design › Manage forms & flows you create and that are shared with you \| Manage › Governed content | — | REST API |
