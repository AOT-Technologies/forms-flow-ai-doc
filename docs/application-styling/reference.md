# Application styling: reference

<span className="badge badge--secondary">Added in 8.4</span>

This page lists every application styling action in formsflow.ai 8.4, the permission each one needs, and where to find it.

## Availability

- **Editions:** Go, Professional, Enterprise
- **Deployment:** SaaS and self-hosted. Self-hosted only: set up logo storage (self-hosted)

## Actions and permissions

Permissions are named as they appear on the role editor in **Manage › Roles**. A user can do an action if any of their roles grants the permission.

| What you want to do | Permission needed | Where to find it | Available through |
| --- | --- | --- | --- |
| Open the Appearance settings | Manage › App styling | Manage › Appearance | formsflow.ai web app |
| Set your organization's display name | Manage › App styling | Manage › Appearance › Display name | formsflow.ai web app, REST API |
| Choose rounded or square buttons | Manage › App styling | Manage › Appearance › Buttons | formsflow.ai web app, REST API |
| Preview your branding before saving | Manage › App styling | Manage › Appearance (right-hand panel) | formsflow.ai web app |
| Set up logo storage (self-hosted) | Server access to your installation (self-hosted) | — | Deployment configuration |
| Upload your organization's logo | Manage › App styling | Manage › Appearance › Logo | formsflow.ai web app, REST API |
| Remove the uploaded logo | Manage › App styling | Manage › Appearance › Logo › trash icon | formsflow.ai web app, REST API |
| Save appearance changes | Manage › App styling | Manage › Appearance › Update | formsflow.ai web app, REST API |
| Restore the default appearance | Manage › App styling | Manage › Appearance › Restore to Default | formsflow.ai web app, REST API |
| See your organization's logo and name in the app | Any signed-in user | Sidebar (expanded); mobile menu | formsflow.ai web app |
