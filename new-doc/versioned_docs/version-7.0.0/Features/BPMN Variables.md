# Flow: Variables

---

BPMN variables are the form fields added to the layout. These fields, if selected, are passed to BPMN during form submission, allowing BPMN to access their values. The selected variables will also be available to be displayed in the task list under Review > Tasks.

1. Create a new form or Edit an already created form

   ![Image](/img/7.0.0/Screenshot-2024-11-26-164256.png)

2. Create your form's layout

3. Switch to the flow of the form by clicking large "Flow" button on the right side

4. On the flow page there is a Variables button on the top left.

   ![Image](/img/7.0.0/Screenshot-2024-11-26-164833.png)

   - Select each field you would like by clicking on it.

     ![Image](/img/7.0.0/Screenshot-2024-11-26-165300.png)

   - On the right side you can see the type of a variable the form's field would provide. Click "Add Variable" if you want to keep this variable for usage in the Flow, Submissions and Tasks. You can also add an alternative label to the variable if you would like. If you want to edit the label of a variable after it has been added, just click the variable pill to bring the settings up.

     ![Image](/img/7.0.0/Screenshot-2024-11-26-165614.png)

5. Once the form is submitted you will have access to the variables you have selected in the previous step in the Review > Tasks. You can click on "Create New Filter" button at the top, or edit a filter that has been created before. In the side popup you can click on "Task attributes" and select which varibles to show.
