# formsflow.ai 8.x documentation

formsflow.ai is a forms and workflow platform: you connect a form to a workflow, and each submission starts the process behind it.

This is the documentation for formsflow.ai version 8. It is written feature by feature, so for now it covers the features listed below. Each page shows the release that added the feature, for example **Added in 8.4**. If your installation runs an earlier 8.x release, a feature marked with a later release isn't available to you yet.

## Features documented so far

- [Offline form submissions](offline-submissions/index.md) (beta): let people fill in forms without a connection, save them on their device, and send them when the connection returns.
- [AI-assisted submissions](ai-assisted-submissions/index.md) (beta): an assistant that answers questions while people fill in your forms, using the knowledge you add to each form.
- [Application styling](application-styling/index.md): put your organization's name, logo and button style on formsflow.ai.
- [Form governance](form-governance/index.md): put approved wording, like privacy and retention notices, on your organization's forms and keep designers from changing it.

Each section starts with an overview of how the feature works and who sets it up, followed by step-by-step pages for each task and a reference page listing every action, who can do it and where to find it.

## Anything not listed here

For topics not yet covered in the 8.x documentation, use the [7.0.0 documentation](/7.0.0/). Some screens and settings differ in version 8, so check the steps against your installation.
