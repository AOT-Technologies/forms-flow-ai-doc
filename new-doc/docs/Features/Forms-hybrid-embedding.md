# Form: Hybrid Embedding

---

Hybrid form embedding is a feature where you can embed both authenticated and anonymous forms in your application. This feature allows user to submit forms from your application.

For more information about form embedding, please refer [here](https://github.com/AOT-Technologies/forms-flow-ai-web-components/tree/main/forms-flow-webcomponent)
