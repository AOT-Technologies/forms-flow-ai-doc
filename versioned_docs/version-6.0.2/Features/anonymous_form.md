# Anonymous Forms

---

An anonymous form allows users to submit form entries anonymously. Users can access the form using the form URL without login to the application.

Below steps describe how you can design a form anonymous:

1. Create a new form or edit an already created form. Check the field asking whether you want to make the form public to make the form available to the public.

   ![Image](/img/166641751-b7f4df20-959d-485a-ac41-cc688e9f6762-(1).png)

2. Associate a workflow if you want and move to the next stage.

   ![Image](/img/Screenshot 2022-06-01 142611.png)

3. In this stage, you can copy the anonymous form URL and publish the form to the client. Forms that are made anonymous and public will only appear publicly.

   ![Image](/img/166641111-41401eb1-4c42-4198-99b5-e66200d20498.png)

   **Note: Forms will not be available to anonymous users if they are not published.**

   ![Image](/img/Screenshot-2022-06-01-143337.png)

4. Designers can share the copied URL to allow other users to submit anonymous forms.

   ![Image](/img/Screenshot-2022-06-01-143743.png)
